# Resume Builder

Конструктор резюме с возможностью предпросмотра в реальном времени и экспортом в PDF.

## 🚀 Возможности

- ✏️ **Редактор резюме** — заполняйте все необходимые секции
- 👤 **Личная информация** — ФИО, должность, контакты, фото
- 💼 **Опыт работы** — добавляйте неограниченное количество мест работы
- 🎓 **Образование** — учебные заведения, степени, специальности
- 💪 **Навыки** — список ваших профессиональных навыков
- 🌍 **Языки** — языки с уровнем владения
- 📜 **Сертификаты** — профессиональные сертификаты и курсы
- 🚀 **Проекты** — ваши проекты с описанием и технологиями
- 👁️ **Предпросмотр в реальном времени** — сразу видите, как будет выглядеть резюме
- 📄 **Экспорт в PDF** — скачайте готовое резюме в один клик
- 💾 **Автосохранение** — данные сохраняются в localStorage

## 🛠️ Технологии

- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик проекта
- **Tailwind CSS** — стилизация
- **Zustand** — управление состоянием
- **html2canvas-pro** — конвертация HTML в изображение
- **jsPDF** — генерация PDF
- **ESLint** — линтер
- **Prettier** — форматирование кода

## 📦 Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/resume-builder.git

# Перейдите в директорию проекта
cd resume-builder

# Установите зависимости
npm install

# Запустите проект
npm run dev
```
